# Governance

Orchestrator begins as a maintainer-led open-source project. The maintainer sets release scope, reviews security-sensitive changes, and protects the project’s core boundaries: local-first operation, provider neutrality, honest evidence, user attention, and source authority.

Substantial decisions should be discussed in public issues with alternatives and affected parties documented. Maintainers may be added based on sustained technical contribution, sound privacy and safety judgment, and respectful community participation.

The project uses Apache-2.0 and the Developer Certificate of Origin rather than a contributor license agreement. Security embargoes and private user data are the narrow exceptions to public decision-making.
