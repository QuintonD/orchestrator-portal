# Invisible OS design reference

The [handoff](INVISIBLE_OS_AGENT_HANDOFF.md) and seven boards are preserved from
the workspace's supplied design package. `manifest.json` lists the original
assets and their reading order. They are reference material, not a description
of features already implemented in Orchestrator.

The current product scope and security boundaries remain in
[product direction](../../docs/product-direction.md) and
[architecture](../../docs/architecture.md). Treat proposed widgets, automation,
and approvals in this handoff as design ideas subject to those boundaries.

Workspace cleanup retained one extracted copy. The original ZIP and duplicate
top-level handoff were moved to the local Git metadata backup directory
`.git/workspace-backups/2026-09-10/`; they were not discarded or added as duplicate
repository assets.
