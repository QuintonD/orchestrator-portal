# Beta implementation and acceptance

> Historical development record. The beta labels below describe the names used during that work, not an approved beta release. The application remains alpha; original results and artifact names are preserved. See [release history](releases.md).

This beta completes the supported local portal workflows. It does not imply a
universal execution adapter, independent verification of arbitrary outcomes,
or permission to send messages, deploy or spend money through connected tools.

## Required acceptance

- Versioned defaults for every supported connection and independent workspace guides.
- Connection-matched selection, idempotent installation, visible execution mode,
  source scope, pause/resume and meaningful first results.
- Local index and workspace guides can update on local source changes without
  model calls. Runtime work requires its confirmed source mandate; handoff-only
  connections generate an explicit handoff.
- Assistant-scoped conversations preserve role, history and identity.
- Reports have findings, recommendations, references and preserved revisions.
- A complete simulated decision journey has options, evidence and consistent
  updates to attention, work and outcome history. Live effects remain source-native.
- Distinct council contributions and synthesis; semantic regression fixtures.
- An outcome-oriented home and compact navigation; responsive and reduced-motion QA.
- Narrow and full tests, adversarial/authority cases, native Android screenshots,
  a working packaged beta candidate and a documented integration acceptance matrix.

## Research informing the defaults (6 September 2026)

| Primary source | Useful pattern | Application here |
| --- | --- | --- |
| [Claude Code subagents](https://code.claude.com/docs/en/sub-agents) | Focused roles, separate context and tool access | A coordinator, an evidence reviewer and follow-up specialist; preserve their identities. |
| [OpenClaw multi-agent routing](https://docs.openclaw.ai/concepts/multi-agent) | Agent-specific state and explicit routing | Distinguish portal roles, native runtime identity and conversation context. A workspace is not a sandbox. |
| [LangGraph persistence](https://docs.langchain.com/oss/javascript/langgraph/persistence) | Durable thread state, interruption recovery | Preserve report revisions and uncertain delivery; never silently retry ambiguous work. |
| [Zapier agent templates](https://zapier.com/templates/agents) | Concrete task templates matched to connected tools | Offer a small useful selection for each source, rather than a generic empty form. |
| [Magentic-UI research](https://www.microsoft.com/en-us/research/publication/magentic-ui-report/) | Low-cost human involvement, plans, action guards and evidence | Prepare options and evidence before requesting a human decision. |
| [T3 Code architecture](https://github.com/pingdotgg/t3code/blob/main/docs/internals/overview.md) | Execution on the host with thin clients | Keep credentials and runtime work on the gateway. |

These are selected examples, not a market-share ranking. The product proposal is
capability-matched teams with an explicit distinction between automatically prepared
local findings, source-executed work and prepared handoffs. The intended advantage
is less operator reconstruction and fewer unnecessary requests; that advantage
requires usability measurement and is not established by automated tests.
